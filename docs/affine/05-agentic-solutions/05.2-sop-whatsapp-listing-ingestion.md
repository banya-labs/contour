# 05.2 — Operational SOP: WhatsApp Voice & Photo Listing Ingestion

> **Agent Code**: `CONTOUR-OPS-01`  
> **Runtime**: Dify AI Backend + Whisper API + Contour `/api/mcp`  
> **Human Supervisor**: Principal Broker / Listing Review Manager  

---

## 1. Purpose & Scope
This companion agent monitors inbound WhatsApp listing submissions from registered field agents. It transcribes audio voice notes, extracts structured property specifications (price, currency, bedrooms, bathrooms, landmark directions), downloads property photos to MinIO S3, and creates a **Pending Review Draft Listing** in Contour.

---

## 2. Execution Pipeline & Data Flow

```
┌──────────────┐         ┌─────────────────────────┐         ┌─────────────────────────┐
│ Field Agent  │ ──────► │ Evolution API / Twilio  │ ──────► │ Whisper & Dify Engine   │
│ (WhatsApp)   │         │ Inbound Webhook         │         │ (Transcription/Extract) │
└──────────────┘         └─────────────────────────┘         └────────────┬────────────┘
                                                                          │
                                                                          ▼
┌─────────────────────────┐         ┌─────────────────────────┐   ┌─────────────────────────┐
│ Manager DocuSign Seam   │ ◄────── │ Contour /api/mcp        │ ◄─┤ Extracted JSON Payload  │
│ (Approval to Publish)   │         │ draft_property_listing  │   │ + MinIO S3 Photo URLs   │
└─────────────────────────┘         └─────────────────────────┘   └─────────────────────────┘
```

---

## 3. Allowed Tools & Security Boundaries
- **Allowed Tools**:
  - `MinIO S3 Client`: Store property media at `s3://contour-vault/{orgId}/drafts/...`
  - `draft_property_listing`: Writes property records with status `DRAFT` only.
- **Forbidden Actions**:
  - The agent is **strictly prohibited** from setting a property status to `PUBLISHED` or `ACTIVE`.
  - The agent **cannot** overwrite existing property records or delete listings.

---

## 4. Extraction Schema Standard

The Dify model extracts unstructured voice notes into this verified JSON structure:

```json
{
  "title": "4 Bedroom Standalone House in Roma Park",
  "listingType": "RENTAL",
  "price": 2800,
  "currency": "USD",
  "bedrooms": 4,
  "bathrooms": 3.5,
  "plotSize": "1,200 sqm",
  "landmarks": "200m inside the main boom gate off Zambezi Road, opposite tennis courts",
  "features": ["Borehole", "Paved yard", "Swimming pool", "Worker quarters"],
  "agentPhone": "+260971766881"
}
```

---

## 5. Rollback & Emergency Kill Switch
If the ingestion agent experiences hallucinations, loops, or payload corruption:
1. Navigate to `/admin/mission-control`.
2. Toggle the **WhatsApp Ingestion Kill Switch** to `OFF`.
3. Incoming WhatsApp messages will route to the human admin inbox immediately.
