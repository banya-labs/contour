## Field-to-Office Automation Seam (Mermaid)

```mermaid
sequenceDiagram
    autonumber
    actor Agent as 📱 Field Agent (Tembo)
    participant WA as 💬 WhatsApp Gateway
    participant AI as 🧠 Whisper & Dify AI
    participant S3 as 🗄️ MinIO S3 Vault
    participant API as ⚡ Contour /api/mcp
    actor Manager as 👔 Managing Broker (Grace)
    participant Web as 🌐 malsproperty.co.zm

    Note over Agent: Standing outside property in Roma Park
    Agent->>WA: Sends 30s Audio Note + 6 Photos + GPS Pin
    WA->>AI: Webhook payload dispatched
    par Audio Processing
        AI->>AI: Whisper speech-to-text transcription
        AI->>AI: LLM structured JSON specification extraction
    and Photo Storage
        AI->>S3: Direct upload to s3://vault/mals/drafts/...
    end
    AI->>API: draft_property_listing(JSON + S3 Photo URLs)
    API-->>Manager: 🔔 Notification: "New Draft Listing Ready for Review"
    Note over Manager: Inspects pricing, landmark directions, and photos
    Manager->>API: Clicks "Approve & Publish" (The DocuSign Seam)
    API->>Web: Webhook updates malsproperty.co.zm live catalog
    API-->>Agent: WhatsApp Alert: "Listing is live! Tap to share WhatsApp Flyer."
```
