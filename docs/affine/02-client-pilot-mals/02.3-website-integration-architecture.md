# 02.3 — Website Integration Architecture: Syncing with malsproperty.co.zm

> **Target Site**: `https://malsproperty.co.zm` (WordPress 6.x + Divi Theme + Essential Real Estate)  
> **Core Requirement**: Provide a fully functional, zero-downtime integration that syncs Contour's live listing inventory into MAL's existing public website without breaking their existing SEO or Divi layouts.

---

## 2. Path A: Headless REST API & Webhook Synchronization (Recommended)

In this model, MAL's WordPress site remains the public marketing face, but Contour acts as the headless inventory brain.

### How It Works:
1. **Contour REST Endpoint**:
   - `GET https://contour.banyalabs.com/api/v1/organizations/{orgId}/properties`
   - Returns sanitized, public-facing property data:
     ```json
     {
       "id": "prop_kabulonga_04",
       "title": "4-Bedroom Executive Townhouse in Kabulonga",
       "slug": "4-bed-executive-townhouse-kabulonga",
       "listingType": "RENTAL",
       "price": 2500,
       "currency": "USD",
       "bedrooms": 4,
       "bathrooms": 3,
       "location": {
         "city": "Lusaka",
         "suburb": "Kabulonga",
         "latitude": -15.4214,
         "longitude": 28.3491,
         "landmarks": "150m off Bishops Road near Kabulonga Boys Secondary School"
       },
       "images": [
         "https://s3.contour.banyalabs.com/contour-vault/mals/photos/img_01.webp"
       ],
       "agent": {
         "name": "Tembo Mwanza",
         "phone": "+260971766881",
         "whatsappUrl": "https://wa.me/260971766881?text=Hi%20Tembo,%20I'm%20inquiring%20about%20the%20Kabulonga%20Townhouse%20(ID:%20prop_kabulonga_04)"
       }
     }
     ```
2. **Automated Webhook Sync**:
   - Whenever an agent publishes or updates a property in Contour, Contour dispatches an HTTP POST webhook to MAL's WordPress site:
     `POST https://malsproperty.co.zm/wp-json/contour/v1/sync`
   - A lightweight WordPress helper plugin updates the Essential Real Estate (ERE) post type in milliseconds.
3. **Key Advantages**:
   - 100% preserves MAL's existing Google rankings and domain authority.
   - Zero change to MAL's hosting or WordPress theme.

## 3. Path B: Embeddable Responsive JavaScript Catalog Widget

For instant deployment without installing WordPress plugins, Contour provides an embeddable, responsive iframe widget.

### Implementation Snippet for Divi Code Module:
MAL's webmaster simply pastes this snippet into any Divi page builder section:

```html
<!-- Contour Embedded Real Estate Catalog for MAL's Property -->
<div id="contour-catalog-root" style="width: 100%; min-height: 800px;">
  <iframe 
    src="https://contour.banyalabs.com/embed/mals-property" 
    style="width: 100%; height: 900px; border: none; border-radius: 12px; box-shadow: 0 4px 20px rgba(0,0,0,0.06);"
    loading="lazy"
    allow="geolocation"
  ></iframe>
</div>
<script src="https://contour.banyalabs.com/widgets/embed.js" async></script>
```

### Widget Features:
- **Automatic Height Resizing**: Dynamically scales to match mobile screens or widescreen desktops without double scrollbars.
- **Brand Consistency**: Styled in MAL's corporate green and warm tones (`#056839`, `#774c29`).
- **Direct WhatsApp Buttons**: Every property card contains a prominent **"Inquire on WhatsApp"** button routing directly to the assigned MAL's agent.
