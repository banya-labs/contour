# 03.7 — Field Agent Mobile PWA (PowerSync Offline & WhatsApp Flyers)

> **Surface Path**: `/kiosk` or `/agent`  
> **Primary Audience**: Field Real Estate Agents, Viewing Coordinators  
> **Form Factor**: High-contrast mobile viewport (`390px` to `428px`), installable Progressive Web App (PWA)  

---

## 1. Feature Definition & Overview

The **Field Agent Mobile PWA** is a purpose-built mobile interface designed for real estate agents working on the road across Southern African cities. It runs entirely offline via **PowerSync** client-side SQLite WASM and provides 2-tap branded WhatsApp flyer generation with strict Landlord PII masking.

---

## 2. Problem Solved, Mechanism & Quantifiable Benefit

### 1. The Regional Problem Solved:
Standard mobile web apps fail in Lusaka because mobile cell coverage drops in outer suburbs, gated estates, and during power load-shedding. When an agent is standing in front of a house with an interested buyer, an app that takes 15 seconds to load or throws a network error is useless. Furthermore, when agents send property photos to buyers over WhatsApp, they frequently forward messy camera rolls, accidentally leaking the landlord's phone number or looking unpolished.

### 2. The Architectural Mechanism:
- **Zero-Install Native PWA**:
  - Installable directly from mobile Safari (iOS) and Chrome (Android) via **"Add to Home Screen"**.
  - No 30% Apple/Google App Store tax, no app store approval delays, and instant background service worker updates.
- **PowerSync Offline-First SQLite WASM Replication**:
  - PostgreSQL changes are streamed via logical WAL replication to PowerSync Cloud/Self-hosted service.
  - The client PWA maintains a local SQLite database running directly in the browser's IndexedDB / WASM engine.
  - **Result**: Searches, filters, map rendering, and spec lookups execute with **zero network latency (0ms)** even in airplane mode.
- **2-Tap Branded WhatsApp Flyer Generator**:
  - When an agent selects a property and taps **"Generate Flyer"**, the PWA synthesizes an image card containing:
    - Agency logo and branding (e.g. MAL's Property Consultancy)
    - High-res cover photo
    - Price in ZMW/USD, bedrooms, bathrooms, plot size
    - Verified landmark directions
    - Agent's name and direct contact phone number
  - **Strict PII Masking**: The landlord's personal phone number, bank account details, and private lockbox codes are completely stripped from the generated flyer.
- **Fast Lead Logger**:
  - A streamlined 3-field modal (Client Name, Phone Number, Budget) allowing agents to log leads in 10 seconds right from their car.

### 3. Quantifiable Business Benefit:
- **100% Field Availability**: Agents never get stuck without property specs, regardless of network load-shedding.
- **Brand Protection & Deal Security**: Prevents prospective buyers from bypassing the agent to contact the landlord directly.
- **High-Velocity Sharing**: Agents send 4x more property flyers per day, driving higher viewing volumes and closed deals.
