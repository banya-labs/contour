# 04.1 — Multi-Tenancy & Tenant Isolation Architecture

> **Architecture Standard**: Better Auth Multi-Tenant Plugin + PostgreSQL Row-Level Scoping + MinIO S3 Namespaces  
> **Core Guarantee**: Complete, cryptographically verifiable isolation between competing real estate brokerages (e.g. MAL's Property Consultancy vs. future client agencies).

---

## 1. Multi-Tenant Architecture Overview

Contour is engineered as a true multi-tenant SaaS platform. While **MAL's Property Consultancy** serves as our premier flagship client, the underlying architecture supports hundreds of independent brokerages operating on the same Dokploy cluster with complete data isolation.

                     ┌──────────────────────┴───────────────────────┐

## 2. The 3 Isolation Layers

### Layer 1: Database & Model Level Isolation
Every single relational entity in Contour's PostgreSQL schema contains a mandatory `organizationId` foreign key:
```prisma
model Property {
  id             String       @id @default(cuid())
  organizationId String
  organization   Organization @relation(fields: [organizationId], references: [id], onDelete: Cascade)
  title          String
  // ...
  @@index([organizationId])
}
```
All API handlers and Prisma database queries wrap their inputs in `createApiHandler()` with an immutable tenant filter:
```typescript
const properties = await prisma.property.findMany({
  where: {
    organizationId: session.organizationId,
    // additional filters...
  }
});
```

### Layer 2: Object Storage Isolation (MinIO S3)
Documents and high-resolution images are strictly isolated by bucket path prefixes:
`s3://contour-vault/{organizationId}/{category}/{timestamp}_{filename}`
Storage policies prevent any tenant from generating presigned URLs for objects outside their dedicated `{organizationId}` folder.

### Layer 3: Machine & MCP Key Isolation
When an agency integrates external AI agents via `/api/mcp`, each Bearer token is bound to a specific user and `organizationId`. Tool calls automatically inherit the authenticated organization's scope; an agent for MAL's can never read or query listings belonging to another brokerage.

## 3. White-Label Customization Engine

Each tenant organization configures its unique brand identity in `/dashboard/settings`:
- **Agency Name & Legal Registration**: (e.g. MAL's Property Consultancy, Rhodes Park, Lusaka)
- **Corporate Colors**: Primary and accent hex codes (e.g. MAL's `#056839` and `#774c29`)
- **Brand Assets**: High-res SVG/PNG logo rendered on WhatsApp flyers, Landlord Remittance statements, and embeddable website widgets
- **Default Currency**: Default view in `ZMW` or `USD` with customizable exchange rates
