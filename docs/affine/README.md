## 🚀 How to Import into Your AFFiNE Workspace

### Method 1: Direct Markdown Import (Recommended)
1. Open your **Contour** workspace in AFFiNE (desktop app or web at `app.affine.pro`).
2. In the left sidebar, click the **"..."** (More options) next to All Pages or Collections.
3. Select **"Import"** $\longrightarrow$ **"Markdown"**.
4. Navigate to `c:\Users\sewar\repos\Contour\docs\affine\` and select the `.md` files to import them directly into your workspace.
5. In AFFiNE, you can create Collections corresponding to the folders:
   - `00 — Workspace Hub`
   - `01 — Business Strategy`
   - `02 — Client Pilot (MAL's Property)`
   - `03 — Feature Breakdown`
   - `04 — Platform Architecture`
   - `05 — Agentic Solutions`
   - `06 — Roadmap & Databases`
   - `07 — Edgeless Canvases`

### Method 2: Converting Tables to Databases in AFFiNE
For the 3 database files in `06-roadmap-and-databases/`:
- `06.2-database-feature-backlog.md`
- `06.3-database-mcp-tool-registry.md`
- `06.4-database-regional-landmines.md`

Once imported into AFFiNE:
1. Highlight the markdown table on the page.
2. Click the table menu and select **"Convert to Database"**.
3. AFFiNE will transform the table into an interactive database where you can toggle between **Table View** and **Kanban Board View** by Status or Priority!

### Method 3: Activating Edgeless Mode (Whiteboards)
For the 3 canvas files in `07-edgeless-canvases/`:
- `07.1-canvas-system-topology.md`
- `07.2-canvas-commission-cashflow.md`
- `07.3-canvas-whatsapp-to-office-seam.md`

1. Open the page in AFFiNE.
2. At the top right, toggle the mode switcher from **Page Mode (Doc)** to **Edgeless Mode (Whiteboard)**.
3. AFFiNE renders an infinite canvas where you can arrange notes, mind maps, and diagrams visually!
