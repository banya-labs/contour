# 05.1 — Three-Bucket Automation Scoping & Task Classification

> **Operating Doctrine**: "Readiness beats hype. Sequence beats sprinting."  
> **Rule**: Before automating any workflow inside Contour, classify the task into one of three distinct buckets to prevent organizational chaos.

---

## 1. The Three-Bucket Framework

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       THREE-BUCKET AUTOMATION MATRIX                        │
├─────────────────────┬─────────────────────────────┬─────────────────────────┤
│ BUCKET 1:           │ BUCKET 2:                   │ BUCKET 3:               │
│ HATE DRAINS         │ ENJOYABLE BUT CHOKING       │ IDENTITY-CRITICAL       │
├─────────────────────┼─────────────────────────────┼─────────────────────────┤
│ Repetitive, low-    │ High-value work that agents │ Core relationship work  │
│ meaning toil staff  │ enjoy, but that creates a   │ where agents stake      │
│ want off their desk │ throughput bottleneck       │ their professional worth│
├─────────────────────┼─────────────────────────────┼─────────────────────────┤
│ ACTION:             │ ACTION:                     │ ACTION:                 │
│ Automate First      │ Automate Volume,            │ Never Automate Directly;│
│ Completely          │ Keep Human in the Loop      │ Build Empowering Tools  │
└─────────────────────┴─────────────────────────────┴─────────────────────────┘
```

## 2. Contour Workflow Classification

### Bucket 1: Hate Drains (Automate First)
- **Rent Arrears Chasing**: Property managers hate calling tenants to ask for late rent. It feels awkward, repetitive, and time-consuming.
  - *Contour Automation*: Automated tiered WhatsApp reminders sent via background BullMQ workers with 4-day cooldown locks.
- **Landlord Remittance Statement Math**: Reconciling bank deposits against plumbing/borehole repair slips and typing up PDF statements.
  - *Contour Automation*: 1-Click calculation of `Gross Rent − 10% Fee − Maintenance = Net Payout`.
- **Property Spec Transcription**: Manually typing bedroom counts, plot dimensions, and features from WhatsApp messages into WordPress.
  - *Contour Automation*: Dify / Whisper automated transcription from voice notes and photos into structured draft listings.

### Bucket 2: Enjoyable but Choking (Automate Volume, Human in Loop)
- **Marketing Flyer Copywriting**: Writing persuasive, elegant descriptions for prime villas in Kabulonga or commercial space in Rhodes Park.
  - *Contour Automation*: AI generates 3 high-converting copy variants; the agent reviews and picks the best one.
- **Comparative Market Valuation**: Pulling recent transaction comparables for a landlord evaluating listing prices.
  - *Contour Automation*: AI queries historical database sales; human broker applies judgment on property condition and road access.

### Bucket 3: Identity-Critical (Never Automate Directly)
- **High-Stakes Landlord Mandate Negotiations**: Convincing a prominent Lusaka landowner to grant an exclusive sole mandate.
  - *Why Never Automate*: The landlord hires the broker for trust, personal presence, and discretion. An AI agent cannot build a handshake relationship.
- **Final Financial Payouts & Legal Signatures**: Authorizing bank wire transfers or signing conveyance deeds.
  - *The DocuSign Seam*: Requires explicit human click authorization.
