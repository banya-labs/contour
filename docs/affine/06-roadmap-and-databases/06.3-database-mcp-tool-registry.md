# 06.3 — AFFiNE Database: MCP Tool & API Registry

> **Machine Surface Catalog**: Standardized Model Context Protocol (MCP) JSON-RPC 2.0 tool contracts for external AI agents, companion bots, and integrations.

---

## 1. Production MCP Tool Catalog

### 🔧 `list_properties`
* **Access Level**: Bearer (Read) • POST (JSON-RPC 2.0)
* **Description**: Searches tenant properties with filters.
* **Primary Parameters**: `listingType`, `suburb`, `minPrice`, `maxPrice`
* **Rate Limit**: 60 requests / min

### 🔍 `get_property_details`
* **Access Level**: Bearer (Read) • POST (JSON-RPC 2.0)
* **Description**: Retrieves full specs, landmarks, and photo URLs.
* **Primary Parameters**: `propertyId`
* **Rate Limit**: 60 requests / min

### 📝 `draft_property_listing`
* **Access Level**: Bearer (Write) • POST (JSON-RPC 2.0)
* **Description**: Ingests draft listing from WhatsApp voice notes or agent text.
* **Primary Parameters**: `title`, `price`, `currency`, `landmarks`, `specs`
* **Rate Limit**: 30 requests / min

### ⚠️ `check_rent_arrears`
* **Access Level**: Bearer (Read) • POST (JSON-RPC 2.0)
* **Description**: Scans active leases for overdue rent.
* **Primary Parameters**: `minDaysOverdue`, `currency`
* **Rate Limit**: 30 requests / min

### 📲 `dispatch_arrears_reminder`
* **Access Level**: Bearer (Write) • POST (JSON-RPC 2.0)
* **Description**: Triggers WhatsApp overdue reminder notice.
* **Primary Parameters**: `leaseId`, `tier`, `overrideCooldown`
* **Rate Limit**: 15 requests / min

### 📊 `get_deal_pipeline_summary`
* **Access Level**: Bearer (Read) • POST (JSON-RPC 2.0)
* **Description**: Summarizes active sales deals and pending 5% commission revenue.
* **Primary Parameters**: `organizationId`
* **Rate Limit**: 60 requests / min

### 📑 `generate_landlord_statement`
* **Access Level**: Bearer (Write) • POST (JSON-RPC 2.0)
* **Description**: Compiles monthly landlord statement draft for human authorization.
* **Primary Parameters**: `propertyId`, `month`, `year`
* **Rate Limit**: 15 requests / min

### 🔒 `revoke_api_key`
* **Access Level**: Super Admin • POST
* **Description**: Immediately blocks compromised Bearer token with HTTP 403.
* **Primary Parameters**: `keyId`
* **Rate Limit**: 10 requests / min
