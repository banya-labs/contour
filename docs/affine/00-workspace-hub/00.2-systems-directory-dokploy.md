## 3. Core Health Probes & Telemetry Endpoints

Every running Contour container exposes automated health, readiness, and metrics endpoints:

1. **Liveness Probe** (`/api/health`):
   - Returns HTTP 200 `{ status: "healthy", timestamp: "..." }` when the Node.js process is active.
2. **Readiness Probe** (`/api/ready`):
   - Confirms active connectivity to PostgreSQL (`prisma.$queryRaw`), Redis cache, and MinIO S3 buckets before accepting incoming web traffic.
3. **Telemetry & Prometheus Metrics** (`/api/metrics`):
   - Scraped by Dokploy health sentry to track response latencies, active memory usage, and background worker queue depth.
