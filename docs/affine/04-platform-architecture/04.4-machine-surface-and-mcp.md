# 04.4 — Machine Surface & MCP Control Plane (/api/mcp)

> **Machine Endpoint**: `/api/mcp` (JSON-RPC 2.0 Protocol)  
> **Key Management Studio**: `/admin/mcp`  
> **Security Protocol**: User-Scoped Bearer Tokens + 3-Layer Sliding Window Rate Limiting  

---

## 1. The Machine Surface Paradigm

In accordance with Banya Labs doctrine, Contour is designed from day one with **dual surfaces**:
1. **The Human Surface**: Web dashboard, mobile PWA, and public listing cards.
2. **The Machine Surface**: A standardized Model Context Protocol (MCP) server running at `/api/mcp`, allowing external AI agents (Dify, Claude Desktop, Antigravity, custom scripts) to interact directly with Contour's inventory, deals, and arrears pipelines.

---

## 2. Multi-Key Lifecycle & 1-Click Compromise Revocation

Unlike primitive platforms that offer a single, shared static API key, Contour implements an enterprise **Multi-Key Lifecycle**:
- Users generate unlimited distinct, named API keys in `/admin/mcp` (e.g. *"MAL's Dify Ingestion Bot"*, *"Managing Director Claude Key"*, *"Field WhatsApp Gateway"*).
- Each key is stored in the database with permissions, `lastUsedAt` timestamp, and status: `active` | `revoked`.
- If a phone is lost or a key is accidentally committed to Git, the user clicks **"Revoke Key"** in the UI. That specific key is blocked immediately with HTTP 403, without invalidating any other operational tokens.

---

## 3. 3-Layer Sliding Window Rate Limiter (Layer 9 Standard)

All machine requests entering `/api/mcp` pass through `src/lib/rate-limiter.ts`:

1. **IP Rate Limit**: 30 GET / 60 POST per minute (`mcp:ip:{ip}`). Protects against discovery flooding.
2. **Bearer Key Rate Limit**: 60 calls per minute (`mcp:key:{tokenHash}`). Prevents runaway agent loops.
3. **Tenant Organization Rate Limit**: 120 calls per minute (`mcp:org:{tenantId}`). Protects downstream database connection pools and MinIO S3 bandwidth.

*Backed by atomic Redis Lua scripts in production, gracefully falling back to an in-memory map during local development.*

## 4. Canonical MCP Tool Manifest

### 🔧 `list_properties`
* **Scope**: Read (JSON-RPC 2.0)
* **Description**: Queries active properties filtered by type, price, bedrooms, and suburb.

### 🔍 `get_property_details`
* **Scope**: Read (JSON-RPC 2.0)
* **Description**: Fetches comprehensive specs, landmark directions, and masked agent info.

### 📝 `draft_property_listing`
* **Scope**: Write (JSON-RPC 2.0)
* **Description**: Ingests draft property specs from WhatsApp voice notes or text (creates draft).

### ⚠️ `check_rent_arrears`
* **Scope**: Read (JSON-RPC 2.0)
* **Description**: Scans active leases and reports tenants with overdue balances.

### 📲 `dispatch_arrears_reminder`
* **Scope**: Write (JSON-RPC 2.0)
* **Description**: Triggers an audited WhatsApp reminder notice (respects 4-day cooldown).

### 📊 `get_deal_pipeline_summary`
* **Scope**: Read (JSON-RPC 2.0)
* **Description**: Summarizes current deals in conveyancing and pending 5% commission revenue.
