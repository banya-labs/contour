## Daily Product Surfaces

### Inventory Dashboard

Primary use: centralized inventory control.

Required view:

- Inventory dashboard with counts and portfolio value.

Required actions:

- Create listing for property or vacant land.
- Set availability status.
- Attach documents.
- Link owner/seller and assigned agent.

### Client Profile

Primary use: CRM, KYC, segmentation, and communication history.

Required actions:

- Capture KYC: NRC/passport and TPIN.
- Apply segment tags.
- Log interactions: calls, visits, negotiations, WhatsApp, email, and other touchpoints.

### Deal Pipeline

Primary use: visual sales management.

Required view:

- Kanban grouped by deal stage.

Required actions:

- Create deal from a client and one or more listings.
- Move stage as progress happens.
- Record offer price and expected close date.
- Assign agent and track commission.

### Installments and Collections

Primary use: hire-purchase and installment receivables.

Required actions:

- Create payment plan from a closed deal.
- Generate schedule rows.
- Record payments.
- Mark schedule items paid.
- Use aging dashboards for follow-ups.

### Rentals and Billing

Primary use: rental contract billing and arrears tracking.

Required actions:

- Create lease.
- Create monthly charges manually in MVP.
- Record payments.
- Track arrears.

### Document Vault

Primary use: file storage, verification, and compliance.

Required actions:

- Upload documents with category tags.
- Mark documents verified.
- Track missing documents per listing, client, and deal.

## Cross-Cutting Workflow

Lead becomes a client record. Agent logs interactions. A deal is created and linked to listings. The deal progresses to contract. It becomes either a sale, installment plan, or lease. Payments and receipts feed reconciliation. Analytics produce insights. Insights create work items.

## UX Implications

- Navigation should be operational, not marketing-led.
- Search and filters are core workflows, especially for agents offline.
- Every dashboard panel should lead to a concrete operational action.
- The web app and Electron desktop app must present the same surfaces and behavior.
