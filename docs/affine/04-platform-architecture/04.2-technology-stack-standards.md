## 2. Strict Architectural Invariants & Pushback Rules

In accordance with the Banya Labs **Venture Architect Pushback Rule**, Contour enforces 4 strict engineering invariants:

1. **No Binary Files in PostgreSQL or MongoDB**:
   - Storing photos, PDF titles, and scans directly in databases causes catastrophic backup bloat and memory exhaustion.
   - All media must stream directly to **MinIO S3** using presigned PUT URLs. The database only stores metadata and S3 URI strings.
2. **Neon / PostgreSQL Connection Pool Discipline**:
   - API routes and Server Actions use pooled connection URLs (`-pooler`) to prevent connection pool exhaustion.
   - Prisma migrations, schema pushes, and seeds strictly use unpooled direct URLs (`POSTGRES_URL_NON_POOLING`).
3. **Dual-Layer Validation Standard**:
   - Layer 1 (Client): Immediate visual feedback on forms (empty check, regex for Zambian NRC `######/##/#`, positive money amounts).
   - Layer 2 (Server): Typed Zod schemas wrapping every API route and MCP tool handler via `createApiHandler()`.
4. **Standalone Production Container Output**:
   - `next.config.mjs` configures `output: "standalone"` to bundle only necessary Node.js dependencies into a lightweight Node 20 Alpine container (under 150MB).
