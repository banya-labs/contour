# 07.2 — Edgeless Canvas 2: Cashflow & Commission Lifecycle Diagram

> **AFFiNE Mode**: Edgeless Whiteboard Canvas  
> **How to Use**: Switch to **Edgeless Mode** to display the financial pipeline and cash flow split mechanics.

---

## Commission & Cashflow Flowchart (Mermaid)

```mermaid
flowchart TD
    subgraph PropertySale ["🏠 Property Sale Event"]
        Sale["Property Sold: $200,000 / K5,000,000\n(e.g. 4-Bed House in Kabulonga)"]
    end

    subgraph GrossCommission ["💵 Gross Commission Calculation"]
        Comm["Gross Agency Commission (5%)\n= $10,000 / K250,000"]
    end

    subgraph StateMachine ["🔄 Commission Lifecycle State Machine"]
        S1["1. EXPECTED\n(Offer Made & Accepted)"]
        S2["2. EARNED\n(Contract Executed)"]
        S3["3. PARTIALLY RECEIVED\n(Deposit with Lawyers Escrow)"]
        S4["4. RECEIVED\n(Full Funds Settled)"]
        S5["5. AGENT PAID OUT\n(Internal Splits Transferred)"]
    end

    subgraph SplitLedger ["✂️ 3-Way Commission Split Ledger"]
        Agency["House Cut: 50%\n$5,000 / K125,000\n(Overhead & Profit)"]
        Listing["Listing Agent: 25%\n$2,500 / K62,500\n(Brought Landlord Mandate)"]
        Closing["Closing Agent: 25%\n$2,500 / K62,500\n(Brought Qualified Buyer)"]
    end

    Sale --> Comm
    Comm --> S1
    S1 --> S2
    S2 --> S3
    S3 --> S4
    S4 --> S5
    S5 --> Agency
    S5 --> Listing
    S5 --> Closing
```
